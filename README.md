# الدهمة للسياحة — النسخة V8 (تصميم فاخر)

موقع React/Vite عربي RTL. الهوية: ليل الحرم + ذهب الكسوة + عاج، وكل الصور داخل إطار "المحراب".

## التشغيل
```
npm install
npm run dev      # للتجربة
npm run build    # للنشر (ينتج مجلد dist)
```
أو افتح `preview/index.html` بالضغط المزدوج لمعاينة سريعة بدون أي تثبيت.

## الصفحات (روابط #)
`#/` الرئيسية · `#/umrah` · `#/hajj` · `#/tourism` · `#/services` · `#/guide` · `#/tools` · `#/about` · `#/contact`

## التعديل
- كل النصوص والأرقام والباقات والصور: `src/data.js`
- الألوان والخطوط: أول `src/styles.css` (متغيرات `:root`)
- رقم واتساب والترخيص: `brand` في `src/data.js`
- الصور في `public/images` والفيديو في `public/videos`
